# Data

This directory contains data used for development, testing, training, and other repository-related purposes. Runtime and user data will not be stored here unless explicitly required.

## Raw

Original or unmodified source data.

## Processed

Data derived or transformed from raw data.

## Generated

Data produced by ODEN or development tools.

The organization and handling of data should be defined in the [Data and Storage](../docs/data/data-and-storage.md) documentation.
